# AGENTS.md

TutorLah is the CS2103T AY26/27 S1 team project of T11-1. Before any task,
read these two files in the repo root:

1. `tutorlah-agent-brief.md`: the team's rules, commands, messages,
   validation, decisions, interfaces and checklists. It wins over other
   team documents.
2. `tutorlah-context.md`: what TutorLah is, who it is for and how it differs
   from AB3.

For any Developer Guide diagram work, also read `tutorlah-uml-guide.md`: the
course's UML expectations, the notation checklist and our PlantUML setup.

Claude Code users: create a local `CLAUDE.md` in the repo root containing
the line `@AGENTS.md`. It is ignored by Git, so each person keeps their own.
